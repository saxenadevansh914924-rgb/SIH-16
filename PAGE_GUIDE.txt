BHOOMI INTELLIGENCE — PAGE-BY-PAGE GUIDE
========================================

Is document mein frontend ke har route/page ka purpose, visible information,
interactions, data source aur prototype limitations detail mein diye gaye hain.
Yeh application demonstration prototype hai. Page par dikhaye gaye records,
metrics, maps ke regional indicators aur activity counts illustrative/demo data
hain; inhe official government statistics ya verified research evidence na
samjhein.


1. APP KA OVERALL STRUCTURE
--------------------------

Frontend React + Vite par chalta hai. Routing React Router se hoti hai. Har
internal page par common application shell rehta hai:

- Left sidebar: sab main pages ke navigation links.
- Top bar: current page breadcrumb, global search/command palette, theme
  control, unread notification indicator aur profile shortcut.
- Main content: route ke hisaab se page.
- Footer: prototype/demo data disclaimer.

Sidebar collapse/expand ho sakti hai. Chhoti screen par menu button drawer kholta
hai; kisi page ko select karne ke baad drawer band hota hai. Theme dark ya light
ki ja sakti hai; preference browser ke localStorage mein `bhoomi-theme` key se
save rehti hai.

Keyboard shortcut CMD+K (Mac) ya CTRL+K (Windows/Linux) command palette kholta
hai. ESC palette/drawer ko band karta hai. Palette research records, datasets,
projects aur GIS page ke matching results dikhati hai. Research result detail
route par, dataset Datasets page par aur project Workspace par le jata hai.

Bookmark, notification aur active form state abhi local React state mein hain;
database ya account sync nahi hai. Page reload par kuch state reset ho sakti hai.

PAGE: AI Research Assistant
Route: /assistant
Component: `Assistant`; server endpoint: `server.js` POST `/api/chat`

Maqsad:
Local research/dataset catalogue se context lekar natural-language Q&A ka demo
dena.

Interface:
- Left conversation history panel aur new-conversation action.
- Center chat: suggested questions, message composer, send button aur response.
- Right evidence panel: sample research papers/dataset cards aur match scores.
- Enter message bhejta hai; Shift+Enter newline ke liye hai.
- New conversation message list clear karta hai.

AI flow:
- Browser `POST /api/chat` ko conversation messages bhejta hai.
- Local Express server OpenAI Node SDK/Responses API ko call karta hai.
- Model setting `OPENAI_MODEL` se; default `gpt-4.1-mini`.
- Server `src/data/research.js` aur `src/data/datasets.js` se catalogue context
  banata hai. Instructions model ko fictional data ko official statistics na
  batane aur catalogue ke titles cite karne ko kehte hain.
- API key sirf server environment (`.env.local`) mein honi chahiye. `VITE_`
  prefix use na karein; frontend bundle mein secret kabhi na rakhein.
- API key absent, request fail ya billing/model access issue ho toh chat mein
  readable error text dikhaya jata hai.

Setup:
`frontend/.env.example` ko `.env.local` mein copy karein, valid/rotated key add
karein, aur `npm run dev` se Vite + API server dono start karein.

Limits:
- Conversation history browser state mein hai; server-side memory/database nahi.
- Evidence panel static demo source cards hai; model output se automated
  citations extraction nahi hoti.
- Responses OpenAI se real-time aate hain, lekin curated corpus chhota local
  prototype data hai; yeh production RAG/vector search nahi.


PAGE: GIS Intelligence
Route: /gis
Component: `GISPage`; map auto-pan helper: `MapFocus`

Maqsad:
Map ke geographic context par fictional region evidence ko explore karna.

Map stack:
- Leaflet + React-Leaflet.
- OpenStreetMap raster tiles: `https://tile.openstreetmap.org/{z}/{x}/{y}.png`.
- OSM attribution map par visible hota hai.
- Tiles internet connection par depend karte hain; tile network fail ho toh map
  error message aur Retry button dikhata hai. Polygon/marker overlays independent
  demo layers hain.

Interactions:
- Map zoom buttons, scroll zoom aur pan support karta hai.
- State polygons aur markers clickable hain; click region select karta hai.
- Selected region change par map uske approximate coordinates par fly-to/zoom
  karta hai.
- Popup region name, project count aur policy indicator dikhata hai.
- State search (example: Rajasthan) + Enter region select/zoom karta hai.
- Layer controls states, districts, research activity, policy indicators aur
  case studies ke display ko control karne ke liye hain.
- Right panel selected state ke projects, datasets, policy studies aur case
  studies count; indicator; research/dataset/analytics shortcuts dikhata hai.
- Mobile par map top par, layer controls aur region summary neeche stack hote
  hain.

Data:
Approximate sample state polygons/coordinates aur counters
`src/data/gisData.js` mein hain. Polygons official GIS boundaries nahi hain.
Tile layer internet se aati hai; prototype geometry local JavaScript hai.

PAGE: Policy Simulation
Route: /simulation
Component: `Simulation`

Maqsad:
Policy assumptions ko adjust karke illustrative baseline-vs-scenario comparison
ka local demonstration.

Inputs:
- Scenario name.
- Land-use allocation (0–100%).
- Urban expansion (0–50%).
- Infrastructure development (0–60%).
- Climate risk factor (0–40%).

Run karne par:
- Local JavaScript formula scenario values calculate karta hai.
- Land-use composition chart baseline aur scenario bars compare karta hai.
- Table agricultural, urban, forest/commons aur other land share ke baseline,
  scenario aur percentage-point change dikhati hai.
- Input badalne par current scenario draft state mein wapas chala jata hai.
- “Save scenario to workspace” result ko localStorage key
  `bhoomi-last-simulation` mein rakhta hai; workspace page par saved strip aati
  hai.

Limitations:
Yeh scientific forecasting model nahi, causal impact analysis nahi, aur official
government forecast nahi. Formula demo values ko illustrate karta hai. Koi
backend, geographic simulation ya policy-model calibration nahi hai.

4. LOCAL RUN
-----------

Terminal se frontend folder mein:

  cd frontend
  npm install
  cp .env.example .env.local

`.env.local` mein OpenAI key set karke dono local processes ek saath chalane ke
liye:

  npm run dev

Vite app aam taur par http://localhost:5173 par khulta hai. `/api` Vite proxy
local Express API (port 3001) par request bhejta hai. OpenAI key ko `.env.local`
mein rakhein, source code mein nahi. GIS base tiles ko dikhne ke liye internet
connection chahiye.
